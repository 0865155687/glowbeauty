# BEAUTY MAKEUP SHOP

## GIỚI THIỆU DỰ ÁN

Beauty Makeup Shop là website bán mỹ phẩm trực tuyến được xây dựng bằng ngôn ngữ PHP và hệ quản trị cơ sở dữ liệu MySQL.

Hệ thống được thiết kế nhằm hỗ trợ khách hàng tìm kiếm, lựa chọn và đặt mua mỹ phẩm trực tuyến một cách thuận tiện. Ngoài ra, website còn cung cấp trang quản trị giúp quản lý sản phẩm, đơn hàng, khách hàng và doanh thu.

## HƯỚNG DẪN TRIỂN KHAI TRÊN HOSTING

### Bước 1: Upload mã nguồn

Upload toàn bộ source code lên thư mục:

```text
public_html
```

hoặc thư mục gốc do nhà cung cấp Hosting quy định.

---

### Bước 2: Tạo cơ sở dữ liệu

Đăng nhập cPanel.

Chọn mục:

```text
MySQL Databases
```

Tạo:

* Database
* User Database

Gán quyền:

```text
ALL PRIVILEGES
```

---

### Bước 3: Import dữ liệu

Đăng nhập phpMyAdmin.

Chọn cơ sở dữ liệu vừa tạo.

Import file:

```text
database.sql
```

---

### Bước 4: Cấu hình kết nối cơ sở dữ liệu

Mở file:

```text
config/database.php
```

Cập nhật thông tin:

```php
Host: localhost
Database: ten_database
Username: ten_user
Password: mat_khau_database
```

---

### Bước 5: Truy cập website

Sau khi hoàn tất cấu hình:

```text
https://tenmiencuaban.com
```

Website sẽ hoạt động bình thường.
